- Cheap-looking icons.

## 4. MULTILINGUAL LANGUAGE SWITCHER

This is a very important requirement.

The default website language must be ROMANIAN.

Create a beautiful language dropdown in the navigation bar.

The dropdown must display:

- Country flag.
- Language abbreviation.
- Language name.

For example:

🇷🇴 RO
🇬🇧 EN
🇫🇷 FR
🇩🇪 DE
🇮🇹 IT

Romanian must be selected by default.

Requirements:

- Clicking the dropdown opens a clean language selection menu.
- Display flags and abbreviations.
- Allow visitors to switch languages instantly.
- Translate all website content, including navigation, buttons, headings, descriptions, forms, property information, and footer content.
- Maintain the selected language while navigating between pages.
- Persist the visitor's language preference using localStorage.
- Use a proper internationalization architecture.
- Avoid translating only the navigation while leaving other content unchanged.
- Format dates, numbers, and currencies appropriately for the selected language.

Use a maintainable translation structure so additional languages are easy to add.

Do not use a flag emoji as the only visual element if proper flag assets are available.

## 7. ANIMATIONS AND SCROLL EXPERIENCE

This is one of the most important parts of the project.

I want the website to feel exceptionally smooth.

Use Framer Motion for animations. Consider GSAP and ScrollTrigger where they provide meaningful additional value.

Implement:

- Smooth section entrance animations.
- Staggered text reveals.
- Image reveal transitions.
- Subtle parallax image movement.
- Scroll-triggered animations.
- Elegant page transitions.
- Smooth navigation transitions.
- Image scaling effects.
- Sophisticated button hover interactions.
- Animated section transitions.
- Subtle background movement.

Scrolling should feel natural and fluid.

Create moments where images move gently as the visitor scrolls, while text enters at carefully timed intervals.

Do not animate everything simultaneously.

Animations must:

- Remain smooth on mobile.
- Avoid excessive CPU and GPU usage.
- Respect reduced-motion accessibility preferences.
- Never interfere with clicking or reading.
- Avoid causing layout shifts.
